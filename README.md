# SAFEKIT

재난 상황별 행동요령과 비상 준비를 돕는 정적 웹사이트입니다.

## 배포

이 저장소는 `dist/` 폴더의 웹사이트를 GitHub Pages로 배포합니다. 저장소 Settings → Pages → Build and deployment에서 Source를 GitHub Actions로 선택하세요. 이후 `main` 브랜치에 변경을 올릴 때 자동 배포됩니다.

## 기능 상태

- 재난별 상황 안내, 설문형 행동 체크, 준비물 목록을 제공합니다.
- 뉴스 키워드 알림, 이메일, 백그라운드 웹 푸시는 연결 전인 시연 기능입니다.
- 상품 링크는 쿠팡으로 이동합니다. 쿠팡 파트너스 링크를 통한 구매가 발생하면 운영자가 수수료를 받을 수 있습니다.
- SAFEKIT은 정부 긴급 경보·구조 요청을 대체하지 않습니다. 급박한 상황에서는 119와 관계 기관 지시를 따르세요.

## 출처

사이트의 공식 출처 페이지에서 재난별 원문과 편집 기준을 확인할 수 있습니다.
